Oct 2026 · ICLR 2027 · Workshop proposal

I'm on the organizing committee of SimWorld: Human and Environment Simulation for Real Intelligence, a workshop proposed for ICLR 2027 together with collaborators from Columbia, NC State, the University of Washington, Meta, and Anthropic. SimWorld treats human and environment simulation as interrelated challenges — realistic interactions need both diverse human behavior grounded in real data and faithful environment dynamics — and asks when simulated interactions can support valid downstream decisions. Topics span human behavior modeling, environment simulation, evaluation and benchmarking, reinforcement learning and agent self-improvement, behavioral alignment, responsible simulation, and real-world deployment. Invited speakers include Dilek Hakkani-Tur, Dakuo Wang, Nicholas Tomlin, and Michel Galley, with a panel featuring Zhou Yu, Tianfu Wu, Han Li, Haoming Jiang, Graham Neubig, and Natasha Jaques. We're recruiting Program Committee members across AI agents, user simulation, HCI, recommender systems, and evaluation — sign up to review.

Oct 2026 · arXiv · New preprint

New preprint: AMBER: Training Long-Horizon Web Agents through Append-Only Memory. Over long, multi-step trajectories, trained overwrite memories tend to delete key facts and the corrective feedback the environment gives back. AMBER (Append-only Memory Bank for Evidence Retention) lets an agent jointly learn to reason, act, and write free-form memory while an append-only rule guarantees retention by construction, so it can be trained end-to-end with reinforcement learning from outcome rewards without curated SFT data. On WebArena Lite, AMBER improves average success over overwrite-based memory by 4.09 points and the fraction of tasks solved in five repeated runs by 4.8 points, matching an overwrite baseline trained on far more expensive curated supervision — all within a practical token budget. The code is open source.

Oct 2026 · NeurIPS 2026 Workshops · Paper accepted

SimTrace: Grounded Multimodal User Trajectories Generation for Online User Modeling has been accepted to two NeurIPS 2026 workshops: Evaluation of Interactive Agents and Who Verifies the Agents? Toward Reliable Agent Development. SimTrace anonymizes real user interactions, builds a simulated twin of the web environment, and uses a grounded computer-use agent to generate faithful, fine-grained synthetic multimodal clickstreams — a shareable alternative to confidential logs. It outperforms baselines on 7 of 8 fidelity metrics; models trained on its synthetic data match real-data performance on purchase prediction and recommendation, and augmenting real data lifts next-action prediction accuracy by 11%. The code is open source.

Sep 2026 · EMNLP 2026 REALM Workshop · Paper accepted

EARS: Explanatory Abstention for Reliable Sub-Agent Modeling in Large-scale Multi-Agent Systems has been accepted to the EMNLP 2026 Workshop for Research on Agent Language Models (REALM). EARS treats sub-agent abstention as an inter-agent communication protocol — instead of over-answering ambiguous or unsupported requests, a sub-agent exposes an actionable failure state to the coordinator for clarification, rerouting, or fallback. On a large-scale e-commerce assistant, EARS raises the response pass rate from 68.5% to 78.9%.
